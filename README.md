## Что нового в 4.0.2

- Панель плеера — настоящее матовое стекло: двухслойный blur с насыщенностью, тонкий хайрлайн и мягкая тень.
- Окно «Что нового» теперь появляется при каждом обновлении и показывает реальные изменения версии.
- Управление плеером с клавиатуры: ⌘P — пауза, ⌘← / ⌘→ — предыдущий и следующий трек.
- Кнопки тулбара плавно подсвечиваются при наведении, панель настроек открывается мягче.
- VPN: двойной клик по серверу подключает, список сортируется по пингу, исправлено зависание ядра Xray при отключении.
- Расширенная блокировка рекламы (noAds V9): +17 рекламных сетей.
- Окно приложения запоминает размер и положение между запусками.

## Возможности

| | |
|---|---|
| 🎧 **Полноценный SoundCloud** | Нативное окно на Swift + AppKit + WebKit — без Electron, без браузера, минимум энергопотребления. |
| 🧊 **Матовый плеер** | Нижняя панель — полупрозрачное стекло с blur и насыщенностью в фирменном монохромном стиле. |
| 🎨 **Настройки оформления** | Минималистичная тёмная тема, белый акцент, скругление обложек, мягкий hover, компактный режим — всё применяется мгновенно, без перезагрузки. |
| 🚫 **noAds V9** | Трёхуровневая блокировка: сетевые запросы, косметическая чистка DOM и пропуск аудиопрероллов. |
| 🔒 **Встроенный VPN** | Xray-core (vless / vmess / trojan / socks) — прокси действует только на DieCloude, система не затрагивается. Ключ подписки хранится в Keychain. |
| ⌨️ **Горячие клавиши** | Управление плеером и навигацией, как в нативном macOS-приложении. |
| 🔄 **Автообновление** | Приложение само проверяет GitHub Releases, скачивает DMG и открывает его. |
| 🔋 **Бережный к батарее** | Дебаунс DOM-наблюдателя, `content-visibility` для длинных лент, низкий QoS фоновых задач. |

## Установка

1. Скачай `DieCloude.dmg` из [последнего релиза](https://github.com/siemens33/DieCloud-MacOS/releases/latest).
2. Открой образ и перетащи **DieCloude.app** в папку **Программы**.
3. Запусти **«Первый запуск DieCloude.command»** (лежит в том же DMG) — он снимет карантин macOS и подпишет приложение. Понадобится пароль администратора.

> Приложение без подписи Developer ID, поэтому первый запуск обрабатывается скриптом. Это разовая операция.

## Горячие клавиши

| Действие | Клавиши |
|---|---|
| Пауза / Воспроизведение | `⌘P` |
| Предыдущий трек | `⌘←` |
| Следующий трек | `⌘→` |
| Назад / Вперёд | `⌘[` / `⌘]` |
| Обновить страницу | `⌘R` |
| Домой | `⌘0` |
| Настройки | `⌘,` |
| Скрыть приложение | `⌘H` |
