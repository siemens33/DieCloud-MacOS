# DieCloude 3.2.0

Нативный клиент SoundCloud для macOS на Swift + AppKit + WebKit.

## Возможности

- Focus Mode, Dynamic Theme, Ambient Background и визуализатор.
- Режим без рекламы.
- VPN только для трафика DieCloude.
- Сохранение подписки Happ в Keychain.
- Автоподключение последнего выбранного VPN-сервера.
- Проверка обновлений через GitHub Releases при запуске и вручную через меню приложения.
- Универсальная сборка Apple Silicon + Intel.



## VPN при запуске

Открой окно VPN, обнови подписку, выбери сервер, подключись и включи «Автоподключение при запуске DieCloude». Последний выбранный сервер и список узлов сохраняются локально. Ключ подписки хранится в Keychain. Отдельный прокси WKWebView требует macOS 14+.
