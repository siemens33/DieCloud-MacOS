# DieCloude

**Версия 4.2.0 · сборка 36 · macOS 14+**

[Скачать последнюю версию](https://github.com/siemens33/DieCloud-MacOS/releases/latest)

Обычное приложение для macOS, которое открывает SoundCloud в отдельном окне. Без браузерных вкладок, без Electron — нативное окно на Swift, поэтому почти не греет ноутбук и не съедает память. Я собрал его для себя, потому что слушать музыку в общей куче вкладок надоело, а официального клиента под macOS у SoundCloud нет.

Что умеет:

- Тёмный монохромный интерфейс поверх сайта — применяется сразу, без перезагрузки страницы. Нижняя панель плеера сделана матовым стеклом с blur, и сквозь неё видно размытый контент.
- Настоящая интеграция с системой: медиа-клавиши F7/F8/F9 и кнопки наушников управляют музыкой, а название трека, исполнитель и обложка показываются в системном меню macOS.
- Режим без рекламы: блокирует рекламные запросы, убирает промо-треки из лент и пропускает аудиопрероллы.
- Четыре цветовых акцента на выбор: белый монохром, янтарный, синий и акцент из настроек macOS.
- Режим фокуса, скругление обложек, компактная плотность — каждый пункт включается отдельно в настройках (⌘,).
- Встроенный VPN, который действует только на DieCloude и не трогает систему: вставляешь ссылку подписки, выбираешь сервер (vless / vmess / trojan / socks), ключ хранится в Keychain.
- Автообновление: приложение само замечает новый релиз на GitHub и скачивает его.

## Что нового в 4.2.0

- **Новый дизайн настроек**: интерфейс переработан в стиле macOS Sonoma/Sequoia — сгруппированные карточки с цветными SF Symbols бейджами, удобный выбор цветового акцента и кнопки быстрых действий.
- **Чистый тулбар**: убраны лишние веб-кнопки навигации — окно стало просторным и минималистичным, навигация работает через нативные жесты трекпада и горячие клавиши.
- **Новый стиль плеера и клиента**: парящая матовая панель плеера с акцентным свечением шкалы и интерактивной кнопкой воспроизведения, полупрозрачная шапка, улучшенные карточки треков.
- **Системное меню «Правка»**: добавлены стандартные горячие клавиши буфера обмена (⌘C, ⌘V, ⌘X, ⌘Z, ⌘A).
- **Исправление багов**: автоматическое восстановление страницы при возвращении сети, устранена утечка Now Playing команд и потенциальный race condition в пинге VPN.

## Установка

1. Скачай `DieCloude.dmg` по ссылке выше и перетащи приложение в Программы.
2. Запусти один раз `Первый запуск DieCloude.command` из образа — он снимет карантин macOS и подпишет приложение (попросит пароль администратора).

Приложение без платной подписи Apple, поэтому первый запуск оформлен скриптом — это разовая история.

## Горячие клавиши

| Действие | Клавиши |
|---|---|
| Пауза / воспроизведение | `⌘P` |
| Предыдущий трек | `⌘←` |
| Следующий трек | `⌘→` |
| Назад / вперёд | `⌘[` / `⌘]` |
| Обновить страницу | `⌘R` |
| Домой | `⌘0` |
| Настройки | `⌘,` |
