# DieCloude

Нативная оболочка SoundCloud для macOS с фирменным монохромным интерфейсом.

**Версия 3.5.2 · сборка 29 · macOS 12+**

[Скачать последнюю версию](https://github.com/siemens33/DieCloud-MacOS/releases/latest)
</div>

## Что нового в 3.5.2

- Нижний плеер получил матовый полупрозрачный фон с системным размытием.
- Исправлены скругления обложек без рваных углов и лишних рамок.
- Добавлены лёгкие анимации обложек и кнопок, не перестраивающие интерфейс SoundCloud.
- Сохранена фирменная чёрно-белая тема DieCloude.

## Возможности

- отдельное нативное окно macOS на Swift, AppKit и WebKit;
- фирменная тёмная тема и белый акцент;
- матовая нижняя панель проигрывателя;
- аккуратное скругление обложек и мягкий hover;
- Focus Mode и скрытие рекламных блоков;
- медиаклавиши и навигация macOS;
- VPN-прокси только для DieCloude на поддерживаемых версиях macOS;
- проверка обновлений через GitHub Releases;
- сборки для Apple Silicon и Intel.

## Настройки

Нажмите **F1** или кнопку с ползунками в верхней панели. Настройки сохраняются автоматически и применяются только внутри DieCloude.

## Установка

1. Скачайте `DieCloude.dmg` из раздела Releases.
2. Перетащите `DieCloude.app` в папку «Программы».
3. Для неподписанной тестовой сборки один раз запустите `Первый запуск DieCloude.command` из DMG.

## Сборка из исходников

Требуются macOS и Xcode Command Line Tools.

```bash
chmod +x "Создать установщик.command"
./"Создать установщик.command"
```

Готовый DMG появится в папке `build`.

## Публикация

```bash
./"Опубликовать обновление.command"
```

Скрипт синхронизирует версию, создаст commit и тег, затем запустит выпуск через GitHub Actions.
