# DieCloude

**Версия 4.5.0 · сборка 41 · macOS 14+**

[Скачать последнюю версию (DMG)](https://github.com/siemens33/DieCloud-MacOS/releases/latest)

Быстрый и удобный клиент SoundCloud для macOS в отдельном окне. Никакого Electron и десятков открытых вкладок браузера — приложение написано нативно на Swift (WebKit), поэтому работает плавно, не съедает оперативную память и не греет ноутбук.

## Возможности

- **Минималистичный тёмный интерфейс**: глубокие тёмные оттенки поверх сайта, аккуратная полупрозрачная шапка и скругление обложек треков.
- **Интеграция с системой и Now Playing**: текущий трек с обложкой отображается в системном меню macOS, поддерживаются мультимедийные клавиши F7/F8/F9 и управление с наушников.
- **Управление с клавиатуры**: пауза и запуск по нажатию `Пробел` (автоматически отключается, когда курсор находится в поле поиска), переключение треков (`⌘←` / `⌘→`) и регулировка громкости (`⌥↑` / `⌥↓`).
- **Режим без рекламы**: блокирует рекламные баннеры, убирает промо-карточки из ленты и глушит аудиопрероллы.
- **Встроенный изолированный VPN**: прокси (Xray) работает только внутри DieCloude и не затрагивает остальные программы и систему. Поддерживаются протоколы VLESS, VMess, Trojan и Shadowsocks.
- **Выбор цветового акцента**: белый монохром, янтарный, синий или системный цвет акцента macOS.
- **Автообновление**: приложение само проверяет наличие новых версий на GitHub.

## Что нового в 4.5.0

- **Починен минималистичный интерфейс**: полностью устранена черная полоса в верхней части окна. Высота шапки зафиксирована на 46 px, вкладки библиотеки аккуратно прилегают к ней, а контент больше не задваивает верхний отступ.
- **Возвращён поиск по любимым трекам**: на странице «Любимые» снова доступны строка фильтрации треков и переключатель вида (плитка / список).
- **Кнопка воспроизведения на обложках**: при наведении курсора кнопка Play плавно увеличивается ровно по центру обложки и больше не смещается в правый нижний угол.
- **Удалена проблемная опция компактности**: убран переключатель «Компактная плотность интерфейса», приводивший к наложению элементов. Отступы и размеры теперь сбалансированы по умолчанию во всех режимах.
- **Управление по клавише «Пробел»**: пауза и воспроизведение по нажатию пробела с защитой текстовых полей ввода.
- **Сохранение и регулировка громкости**: громкость запоминается между запусками, добавлены сочетания `⌥↑` / `⌥↓` для изменения уровня и `⌥M` для быстрого отключения звука.
- **Модульная структура проекта**: исходный код разбит на понятные модули (App, Models, UI, Services, Web), что повысило стабильность и отзывчивость приложения.

## Установка

1. Скачайте `DieCloude.dmg` со [страницы релизов](https://github.com/siemens33/DieCloud-MacOS/releases/latest).
2. Откройте образ и перетащите `DieCloude.app` в папку **«Программы»**.
3. При первом запуске запустите скрипт `Первый запуск DieCloude.command` из образа — он снимет карантин macOS (требуется один раз).

## Горячие клавиши

| Действие | Сочетание клавиш |
|---|---|
| Пауза / Воспроизведение | `Пробел` или `⌘P` |
| Следующий трек | `⌘→` |
| Предыдущий трек | `⌘←` |
| Громче / Тише | `⌥↑` / `⌥↓` |
| Включить / Выключить звук | `⌥M` |
| Назад / Вперёд по истории | `⌘[` / `⌘]` |
| Обновить страницу | `⌘R` |
| На главную (Discover) | `⌘0` |
| Настройки оформления | `⌘,` |
| Закрыть настройки | `Esc` |
