# DieCloude

**Версия 4.0.2 · сборка 33 · macOS 14+**

[Скачать последнюю версию](https://github.com/siemens33/DieCloud-MacOS/releases/latest)

Обычное приложение для macOS, которое открывает SoundCloud в отдельном окне. Без браузерных вкладок, без Electron — нативное окно на Swift, поэтому почти не греет ноутбук и не съедает память. Я собрал его для себя, потому что слушать музыку в общей куче вкладок надоело, а официального клиента под macOS у SoundCloud нет.

Что умеет:

- Тёмный монохромный интерфейс поверх сайта — применяется сразу, без перезагрузки страницы. Нижняя панель плеера сделана матовым стеклом с blur.
- Режим без рекламы: блокирует рекламные запросы, убирает промо-треки из лент и пропускает аудиопрероллы.
- Режим фокуса, скругление обложек, компактная плотность — каждый пункт включается отдельно в настройках (⌘,).
- Встроенный VPN, который действует только на DieCloude и не трогает систему: вставляешь ссылку подписки, выбираешь сервер (vless / vmess / trojan / socks), ключ хранится в Keychain.
- Управление плеером с клавиатуры и автообновление: приложение само замечает новый релиз на GitHub и скачивает его.

## Что нового в 4.0.2

- Матовая панель плеера переделана в двухслойное стекло — больше не выглядит прозрачной.
- Окно «Что нового» появляется при каждом обновлении версии.
- Горячие клавиши плеера: ⌘P — пауза, ⌘← / ⌘→ — переключение треков, кнопка паузы в тулбаре.
- Кнопки тулбара плавно подсвечиваются при наведении, панель настроек открывается мягче.
- VPN: двойной клик по серверу подключает, список сортируется по пингу, исправлено зависание Xray при отключении.
- Блокировка рекламы расширена до 40 правил.
- Окно запоминает размер и положение между запусками.

## Установка

1. Скачай `DieCloude.dmg` по ссылке выше и перетащи приложение в Программы.
2. Запусти один раз `Первый запуск DieCloude.command` из образа — он снимет карантин macOS и подпишет приложение (попросит пароль администратора).

Приложение без платной подписи Apple, поэтому первый запуск оформлен скриптом — это разовая история.

## Горячие клавиши

| Действие | Клавиши |
|---|---|
| Пауза / воспроизведение | `⌘P` |
| Предыдущий трек | `⌘←` |
| Следующий трек | `⌘→` |
| Назад / вперёд | `⌘[` / `⌘]` |
| Обновить страницу | `⌘R` |
| Домой | `⌘0` |
| Настройки | `⌘,` |
