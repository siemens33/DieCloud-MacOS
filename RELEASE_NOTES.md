# DieCloud 5.0.0 (Global Release)

Глобальный релиз DieCloud! Проект выходит на мультиплатформенность: теперь наш клиент SoundCloud доступен не только для macOS, но и в полноценной нативной редакции для Windows.

В этом обновлении мы полностью переработали работу со звуком, добавили удобную настройку Discord Rich Presence прямо в интерфейс и устранили скрытые ошибки.

## Что нового

- **Премьера DieCloud для Windows**:
  - Полноценная нативная версия без Electron на базе C# (.NET 8) и системного движка Microsoft WebView2 (Chromium).
  - Стильный тёмный интерфейс в духе Windows 11 с поддержкой размытия Mica / Acrylic.
  - Интеграция с мультимедийными клавишами Windows, экраном блокировки и системным регулятором звука (SMTC).
  - Удобные горячие клавиши: `Пробел` (пауза/воспроизведение), `Ctrl + →` / `Ctrl + ←` (следующий/предыдущий трек), `Alt + ↑` / `Alt + ↓` (громкость), `Alt + M` (звук вкл/выкл).

- **10-полосный эквалайзер теперь работает со 100% треков**:
  - Раньше на части треков эквалайзер мог молча отключаться из-за строгих правил безопасности браузера (CORS).
  - Теперь приложение на лету перехватывает создание аудиопотоков и выставляет нужные заголовки, благодаря чему эквалайзер и мягкий компрессор нормализации звука работают стабильно на абсолютно каждом треке.

- **Настройка Discord Client ID прямо в интерфейсе**:
  - Больше никаких команд в Терминале. В боковую панель настроек добавлено поле для ввода Discord Client ID.
  - Из коробки уже встроен проверенный рабочий ID — Rich Presence включается одним тумблером. А если хотите своё название и иконку в статусе — просто укажите свой ID в поле, плеер переподключится сразу.

- **Исправления ошибок и оптимизация**:
  - Поле ввода Discord ID теперь корректно сохраняет значение при клике в любую область экрана (по потере фокуса).
  - Устранена скрытая утечка памяти при многочасовом воспроизведении музыки (отработавшие аудиоплееры вовремя удаляются из памяти).
  - Улучшена надёжность переподключения сокетов Discord при выходе из спящего режима.

## Как скачать и установить

- **macOS**: скачайте образ `DieCloude.dmg` из блока Assets ниже, откройте его и перетащите иконку в папку «Программы».
- **Windows**: скачайте `DieCloud-Windows.zip` из блока Assets ниже.
