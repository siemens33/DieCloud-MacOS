# DieCloude 3.5.0 — исправленная тёмная тема

## Что исправлено

- Исправлено отображение в тёмной теме SoundCloud.
- Ambient Background больше не накладывается поверх сайта.
- Glass UI больше не изменяет случайные блоки страницы.
- Карточки, изображения и нижний плеер сохраняют правильные размеры.
- Экспериментальные эффекты по умолчанию отключены, но доступны по F1.
- Сохранена возможность включать каждый эффект отдельно.

## Сборка

Версия 3.5.0, сборка 18.
