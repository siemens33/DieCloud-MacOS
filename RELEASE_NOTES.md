# DieCloude 4.5.0

## Что изменилось

- **Починен минималистичный интерфейс**: полностью устранена черная полоса в верхней части окна. Шапка зафиксирована на 46 px, навигация медиатеки аккуратно прилегает к ней, а верхние отступы контента выровнены.
- **Возвращён поиск по любимым трекам**: на странице «Любимые» (`/you/likes`) снова работает строка фильтрации треков и переключение отображения (плитка / список).
- **Исправлена кнопка Play на обложках**: при наведении курсора кнопка воспроизведения плавно масштабируется строго по центру обложки, больше не улетая в угол.
- **Удалена проблемная опция компактности**: переключатель «Компактная плотность интерфейса» убран из настроек. Все отступы теперь оптимизированы и гармонично сбалансированы по умолчанию.
- **Управление по клавише «Пробел»**: пауза и запуск трека по нажатию пробела с автоматической блокировкой при вводе поисковых запросов.
- **Управление громкостью**: сохранение уровня звука между перезапусками, горячие клавиши `⌥↑` / `⌥↓` и быстрое выключение `⌥M`.
