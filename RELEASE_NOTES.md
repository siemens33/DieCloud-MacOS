# DieCloude 4.1.1

## Что изменилось

- Исправлена блокировка рекламы из тулбара и меню ⌘⇧A: сетевые правила WebKit снова включаются и выключаются вместе с тумблером.
- VPN больше не оставляет «мёртвый» прокси в WebView, если процесс Xray упал — соединение сбрасывается, статус в окне VPN обновляется.
- Движок темы не теряет DOM-мутации во время дебаунса: реклама и аудио обрабатываются надёжнее, при большой пачке узлов — один быстрый проход.
- Быстрее старт: theme-engine.js кэшируется в памяти, правила adblock берутся из кэша WebKit без перекомпиляции.
- Стабильнее Now Playing: слабая ссылка на message handler, корректная отписка при выходе.
