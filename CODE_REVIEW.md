# Проверка и оптимизация DieCloude 3.4.0

## Исправлено

- Тяжёлый `MutationObserver` больше не отслеживает изменения атрибутов всего DOM и не сканирует все `div/article/li` после каждого изменения.
- Пользовательский JavaScript внедряется только в главный frame, а не во все iframe.
- Поиск обложки выполняется с debounce 700 мс и только после добавления изображений.
- Подключение VPN выполняется вне главного потока, поэтому интерфейс не блокируется на время запуска Xray.
- stdout/stderr Xray больше не записываются в непрочитанные `Pipe`, которые могли заполниться и остановить процесс.
- Проверка пинга сериализована на отдельной очереди, что устраняет гонку вокруг флага завершения.
- Обновляется только изменившаяся строка таблицы пинга вместо полной перерисовки таблицы.
- VMess теперь корректно принимает URL-safe Base64 (`-` и `_`).
- Shadowsocks удалён из заявленных форматов, потому что генерация соответствующего outbound отсутствовала.

## Выполненные проверки

- `Info.plist` успешно разобран стандартным Python `plistlib`.
- Встроенный JavaScript успешно прошёл `node --check`.
- Версия синхронизирована: приложение `3.4.0`, build `15`, DMG `3.4.0`.

## Ограничение проверки

Полную компиляцию AppKit/WebKit-приложения можно выполнить только на macOS с Xcode Command Line Tools. В текущем Linux-окружении фреймворки AppKit и WebKit отсутствуют, поэтому реальная сборка должна окончательно проверяться GitHub Actions на `macos`.
