# История изменений

## 4.1.0 — build 34

### Добавлено

- Системная интеграция плеера: медиа-клавиши F7/F8/F9, кнопки наушников и экран блокировки управляют воспроизведением; трек, исполнитель, обложка и позиция видны в системном Now Playing; перемотка ползунком из системного меню.
- Цветовые темы акцента: монохром (по умолчанию), янтарный, синий и акцент macOS — popup в панели настроек; шкала времени, громкость и акцентные кнопки окрашиваются в тон.
- Встроенная страница ошибки соединения с кнопками «Повторить» и «Скрыть» вместо модального алерта; исчезает сама, когда соединение восстановилось.
- Диагностика движка: если панель плеера не нашлась (SoundCloud изменил разметку), приложение показывает тихий баннер раз за запуск и статус в панели настроек.

### Исправлено

- Панель плеера выглядела прозрачной: правила прозрачности внутренностей перебивали стеклянную заливку. Плеер переписан на явные селекторы, сквозь стекло снова просвечивает размытый контент.
- Автообновление «не находило» релизы, помеченные как prerelease (случилось с v4.0.2): проверка теперь читает список релизов и выбирает самый новый опубликованный с DMG; понятные тексты ошибок для лимитов GitHub; кнопка «Пропустить эту версию».

### Изменено

- Дизайн приложения обновлён: панель настроек — секции с описаниями и нативные тумблеры вместо галочек и рамок; окно VPN в том же стиле (точка статуса, аккуратная таблица, тумблер автоподключения); кнопки тулбара с мягкой подсветкой при наведении.
- Тёмный стиль дозалит на всплывающие меню, диалоги, тосты и скроллбары.
- Обновление версии до 4.1.0 отображается в CI: релиз всегда публикуется с меткой Latest.

## 4.0.2 — build 33

### Изменено

- Панель плеера — настоящее матовое стекло: двухслойный blur с насыщенностью, тонкий хайрлайн и мягкая тень. Внутренняя планка получила лёгкую вуаль вместо собственного blur, чтобы стекло не складывалось дважды.
- Окно «Что нового» появляется при каждом обновлении и показывает реальные изменения версии (ключ автосейва версионируется автоматически).
- Управление плеером с клавиатуры: ⌘P — пауза, ⌘← / ⌘→ — переключение треков; кнопка паузы добавлена в тулбар.
- Кнопки тулбара плавно подсвечиваются при наведении и мягко гаснут, когда действие недоступно.
- Панель настроек: появление с анимацией прозрачности, мягкая тень, переключатели собраны в единый реестр настроек.
- VPN: подключение двойным кликом по серверу, сортировка списка по пингу после проверки, подписка подтягивается сама при первом открытии, Enter в поле ключа обновляет список.
- Исправлено: ядро Xray могло остаться работать в фоне после отключения VPN; окно VPN снова открывалось после закрытия крестиком.
- Расширена блокировка рекламы (noAds V9): +17 рекламных сетей (DoubleVerify, Teads, CasaleMedia, 33Across и другие).
- Окно приложения запоминает размер и положение между запусками; закрытие окна теперь завершает приложение.
- Монохромные play-кнопки на обложках и белый ползунок громкости в тон шкале времени.

### Сохранено

- Фирменная монохромная тема и вся геометрия SoundCloud.
- Стек Swift AppKit + WebKit, минимальный таргет macOS 14.
- noAds — трёхуровневая схема: network-правила + косметика + пропуск аудиорекламы.

## 4.0.0 — build 31

### Изменено

- Минимальная версия macOS поднята до 14.0.

### Сохранено

- Фирменная монохромная тема.
- Ad-hoc подпись + `Первый запуск DieCloude.command`.
- Swift AppKit + WebKit — самый холодный стек, язык не менялся.
