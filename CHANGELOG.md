# История изменений

## 4.0.0 — build 31

### Изменено

- Минимальная версия macOS поднята до 14.0.
- Горячая клавиша настроек: ⌘, вместо F1.
- noAds V8: трёхуровневая блокировка (network + косметика + аудио), исправлена неработающая блокировка V6.
- Xray-core v26.3.27 с проверкой sha256, безопасный конфиг, healthcheck запуска.
- Снижено энергопотребление: дебаунс JS-наблюдателя, лёгкий blur, лимит пинга.
- Окно «Что нового» после обновления показывает актуальные изменения версии.

### Сохранено

- Фирменная монохромная тема.
- Ad-hoc подпись + `Первый запуск DieCloude.command`.
- Swift AppKit + WebKit — самый холодный стек, язык не менялся.

## 3.5.2 — build 29

### Изменено

- Нижняя панель проигрывателя получила матовый полупрозрачный фон с blur-эффектом.

- Добавлены лёгкие анимации появления обложек, hover и нажатия кнопок.
- README полностью очищен и обновлён под текущую версию.

### Сохранено

- Фирменная монохромная тема build 25.
- Штатная геометрия плеера и шкалы времени SoundCloud.
