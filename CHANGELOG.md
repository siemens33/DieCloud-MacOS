### Добавлено

- Современный фирменный дизайн DieCloude поверх веб-интерфейса SoundCloud.
- Отдельные переключатели для стеклянных панелей, скруглённых карточек и компактного режима.

- Плавная прокрутка и режим сниженной анимации.
- Прокручиваемая панель настроек по клавише F1.
- Сохранение каждого визуального параметра между запусками.

### Изменено

- Версия приложения повышена до 3.5.0, номер сборки — до 17.
- README дополнен разделом «Что нового» и полным описанием визуальных настроек.
- Скрипт публикации подготавливается к автоматическому обновлению README при каждом релизе.

### Оптимизация

- Анимации выполнены преимущественно через CSS transform/opacity, чтобы уменьшить число перерасчётов layout.
- Режим сниженной анимации отключает переходы, вращение, пульсацию и плавную прокрутку.
- Системная настройка `prefers-reduced-motion` также учитывается.

## 3.4.0

- Снижен объём JavaScript-наблюдений на странице SoundCloud: обработка выполняется только для новых DOM-узлов.
- Инъекция интерфейсного скрипта ограничена главным фреймом, чтобы не создавать наблюдатели во вложенных iframe.
- Поиск обложки ограничен и выполняется с задержкой вместо запуска при каждом DOM-изменении.
- Подключение Xray перенесено с главного потока, поэтому окно приложения не должно подвисать при включении VPN.
- Вывод Xray перенаправлен в `/dev/null`, что исключает заполнение нечитавшихся каналов `Pipe`.
- Исправлена гонка данных при одновременной проверке пинга серверов.
- Исправлена обработка URL-safe Base64 в VMess.
- Убран SS из списка заявленной поддержки: текущий генератор конфигурации Xray его не реализовывал.
