# История изменений

## 4.4.0 (Pre-release) — build 39

### Изменено

- **Временное отключение функций оформления**: переключатели «Минималистичный интерфейс» и «Компактная плотность интерфейса» отключены при запуске и заблокированы в настройках с пометкой «сломана и уже чинится».

### Добавлено

- **Плотная матовая нижняя панель плеера**: панель и её внутренний контейнер получили непрозрачный глубокий матовый графитовый фон (`#111318`), исключающий просвечивание треков и обложек снизу страницы.
- **Стеклянные круглые кнопки паузы на обложках**: при воспроизведении трека кнопка паузы по центру обложки остаётся идеальным кругом с белыми полосками и акцентным свечением вместо квадратной тёмной плашки.

### Исправлено

- **Полная ликвидация лагов при скролле**: отключены ресурсоёмкие анимации списков `dcFadeIn` и `dcArtworkIn`, убраны медленные софтверные CSS-маски (`mask-image`) на обложках в пользу аппаратного `border-radius`, ликвидирован reflow-цикл с `getBoundingClientRect()` в MutationObserver (устранено падение FPS при скроллинге медиатеки и лент).
- **Починены скрипты в папке `scripts/`**: в «Заменить на последнюю сборку» добавлена автоматическая сборка при отсутствии бинарника, в `package-dmg.sh` версия считывается динамически из `Info.plist`, а `build.sh` теперь кэширует Xray-core локально без повторных загрузок по сети.
- **Нижний отступ медиатеки**: для `.l-container` установлен комфортный отступ `96px`, исключающий перекрытие последнего ряда треков нижней панелью плеера.

## 4.2.0 — build 36

### Добавлено

- **Новый дизайн панели настроек**: интерфейс переработан в стиле macOS Sonoma/Sequoia с группировкой по карточкам, цветными бейджами с SF Symbols и быстрым выбором цветового акцента через сегментированный переключатель.
- **Новый дизайн клиента**: плавающая матовая панель плеера с акцентным свечением шкалы и тактильной анимацией кнопки воспроизведения, полупрозрачная размытая шапка сайта, глубокие тёмные тона поверх интерфейса SoundCloud.
- **Системное меню «Правка»**: стандартные пункты Undo/Redo, Cut, Copy, Paste, Select All для работы с текстом в окне.

### Исправлено

- **Плотная матовая нижняя панель плеера**: панель и её внутренний контейнер получили непрозрачный глубокий матовый фон (`#111318`), исключающий просвечивание треков и обложек снизу страницы.
- **Устранены лаги при скролле**: отключены ресурсоёмкие анимации списков `dcFadeIn`/`dcArtworkIn`, убраны медленные софтверные CSS-маски (`mask-image`), ликвидирован цикл с `getBoundingClientRect()` в MutationObserver (устранено падение FPS при прокрутке).
- **Кнопка паузы на обложках**: при играющем треке кнопка паузы по центру обложки остаётся идеальным кругом с акцентным свечением вместо квадратной тёмной плашки.
- **Починены скрипты в папке `scripts/`**: в «Заменить на последнюю сборку» добавлена автоматическая сборка при отсутствии бинарника, в `package-dmg.sh` версия считывается динамически из `Info.plist`, а `build.sh` теперь кэширует Xray-core локально без повторных загрузок по сети.
- Убраны лишние веб-кнопки навигации (назад, вперёд, обновить, домой, плей/пауза) из тулбара — окно избавилось от визуального шума и стало выглядеть как современное нативное приложение macOS.
- Экран ошибки сети теперь автоматически проверяет соединение каждые 5 секунд и бесшовно перезагружает домашнюю страницу при восстановлении интернета.
- Устранена потенциальная утечка памяти в `NowPlayingController` при снятии системных команд плеера.
- Исправлен race condition в окне VPN при одновременном пинге серверов и обновлении списка.
- Добавлено хэширование содержимого правил AdBlock для своевременной инвалидации кэша WebKit.

### Изменено

- Высота тулбара оптимизирована до 44 pt, обеспечив гармоничное выравнивание с системными кнопками закрытия/сворачивания окна.
- Улучшена производительность: раздельное кэширование шаблона JS-движка, оптимизация частоты дебаунса MutationObserver и планирование применения CSS-классов через `requestAnimationFrame`.

## 4.1.1 — build 35

### Исправлено

- Кнопка «Режим без рекламы» в тулбаре и пункт меню ⌘⇧A меняли только флаг/JS, но не WKContentRuleList — сетевая блокировка могла оставаться в старом состоянии до перезапуска.
- Health-check VPN останавливал Xray при недоступности SoundCloud и не сбрасывал proxyConfigurations у WKWebView — страница продолжала ходить в мёртвый локальный порт.
- MutationObserver theme-engine отбрасывал новые DOM-узлы, пока шёл дебаунс 180 мс — часть рекламы/аудио могла не обработаться.

### Изменено

- Кэш theme-engine.js в памяти приложения; lookUp кэша WKContentRuleList перед compile.
- Now Playing: weak-прокси для WKScriptMessageHandler, снятие remote commands и bridge при выходе.
- Остановка Xray: мягкий terminate → interrupt → SIGKILL, чтобы ядро не зависало в фоне.
- Кнопка adblock в тулбаре подсвечивается, когда режим включён.

## 4.1.0 — build 34

### Добавлено

- Системная интеграция плеера: медиа-клавиши F7/F8/F9, кнопки наушников и экран блокировки управляют воспроизведением; трек, исполнитель, обложка и позиция видны в системном Now Playing; перемотка ползунком из системного меню.
- Цветовые темы акцента: монохром (по умолчанию), янтарный, синий и акцент macOS — popup в панели настроек; шкала времени, громкость и акцентные кнопки окрашиваются в тон.
- Встроенная страница ошибки соединения с кнопками «Повторить» и «Скрыть» вместо модального алерта; исчезает сама, когда соединение восстановилось.
- Диагностика движка: если панель плеера не нашлась (SoundCloud изменил разметку), приложение показывает тихий баннер раз за запуск и статус в панели настроек.

### Исправлено

- Панель плеера выглядела прозрачной: правила прозрачности внутренностей перебивали стеклянную заливку. Плеер переписан на явные селекторы, сквозь стекло снова просвечивает размытый контент.
- Автообновление «не находило» релизы, помеченные как prerelease (случилось с v4.0.2): проверка теперь читает список релизов и выбирает самый новый опубликованный с DMG; понятные тексты ошибок для лимитов GitHub; кнопка «Пропустить эту версию».

### Изменено

- Дизайн приложения обновлён: панель настроек — секции с описаниями и нативные тумблеры вместо галочек и рамок; окно VPN в том же стиле (точка статуса, аккуратная таблица, тумблер автоподключения); кнопки тулбара с мягкой подсветкой при наведении.
- Тёмный стиль дозалит на всплывающие меню, диалоги, тосты и скроллбары.
- Обновление версии до 4.1.0 отображается в CI: релиз всегда публикуется с меткой Latest.

## 4.0.2 — build 33

### Изменено

- Панель плеера — настоящее матовое стекло: двухслойный blur с насыщенностью, тонкий хайрлайн и мягкая тень. Внутренняя планка получила лёгкую вуаль вместо собственного blur, чтобы стекло не складывалось дважды.
- Окно «Что нового» появляется при каждом обновлении и показывает реальные изменения версии (ключ автосейва версионируется автоматически).
- Управление плеером с клавиатуры: ⌘P — пауза, ⌘← / ⌘→ — переключение треков; кнопка паузы добавлена в тулбар.
- Кнопки тулбара плавно подсвечиваются при наведении и мягко гаснут, когда действие недоступно.
- Панель настроек: появление с анимацией прозрачности, мягкая тень, переключатели собраны в единый реестр настроек.
- VPN: подключение двойным кликом по серверу, сортировка списка по пингу после проверки, подписка подтягивается сама при первом открытии, Enter в поле ключа обновляет список.
- Исправлено: ядро Xray могло остаться работать в фоне после отключения VPN; окно VPN снова открывалось после закрытия крестиком.
- Расширена блокировка рекламы (noAds V9): +17 рекламных сетей (DoubleVerify, Teads, CasaleMedia, 33Across и другие).
- Окно приложения запоминает размер и положение между запусками; закрытие окна теперь завершает приложение.
- Монохромные play-кнопки на обложках и белый ползунок громкости в тон шкале времени.

### Сохранено

- Фирменная монохромная тема и вся геометрия SoundCloud.
- Стек Swift AppKit + WebKit, минимальный таргет macOS 14.
- noAds — трёхуровневая схема: network-правила + косметика + пропуск аудиорекламы.
